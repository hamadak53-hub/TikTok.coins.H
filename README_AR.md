# HAMO STORE — مشروع بوت تليجرام

هذه نسخة بداية قابلة للتشغيل والاختبار: قائمة باقات تجريبية، إدخال TikTok ID، فاتورة Telegram Stars، حفظ الطلبات في SQLite، وتنبيه المشرفين.

## التثبيت
1. أنشئ بوتًا من @BotFather باستخدام /newbot.
2. انسخ `.env.example` إلى `.env`.
3. ضع BOT_TOKEN ورقم Telegram user ID الخاص بك في ADMIN_IDS.
4. ثبّت Python 3.10 أو أحدث، ثم نفّذ:
   `pip install -r requirements.txt`
5. شغّل: `python bot.py`

## تنبيهات مهمة
- أسعار الباقات وعدد Stars تجريبية ويجب تعديلها.
- لم يتم ربط مورد شحن فعلي. ملف `app/supplier.py` واجهة فارغة عمدًا حتى استلام توثيق المورد الرسمي والموافقة على حسابك والتأكد من دعم مصر.
- لا تفعّل البيع الحي قبل اختبار الدفع، حالات الفشل، الاسترداد، ومنع تكرار الطلبات.
- وفق شروط Telegram الحالية، بيع السلع الرقمية داخل البوت يجب أن يكون عبر Telegram Stars (XTR)، وليس بوابة دفع خارجية بالجنيه المصري. يمكن الاحتفاظ بالجنيه كعملة حسابات داخلية.
- لا ترسل Bot Token أو API Key لأي شخص. احتفظ بها في ملف `.env` على السيرفر.
